Firmware Yükleyici

Cihazını seç, USB ile bağla, tarayıcıdan yaz. Program kurmak gerekmez.

Bu tarayıcı USB seri bağlantısını (Web Serial) desteklemiyor. Chrome veya Edge (bilgisayarda) ile açın.

1. Cihazı seç

2. Yaz

Önce yukarıdan bir cihaz seçin.

Nasıl çalışır?

  1. Kartı USB ile bilgisayara bağlayın (gerekirse kartın bağlantı notuna bakın).
  2. Cihazı seçin, Yükle'ye basın, açılan pencereden kartın COM (seri) portunu seçin.
  3. "Temizle" seçeneğini işaretlerseniz kart tamamen silinir (ilk kurulum için önerilir; eski WiFi ve ayarlar gider).
  4. Yazma bitince kart yeniden başlar. Röle düğümleri ESP01_SETUP (C3: C3_SETUP, ESP32: ESP32_SETUP, S3: S3_SETUP) adlı bir WiFi ağı açar; telefondan bağlanıp evin WiFi'sini seçin. CrowPanel HUB kurulumu ekrandan yapılır.
Yükleme ESP Web Tools ile yapılır (Apache-2.0). İmajlar bu depodaki firmware/ klasöründedir.
